We are pleased to announce the **first release of [nf-core/seqsubmit](https://nf-co.re/seqsubmit)**, a new Nextflow pipeline built by MGnify team members that automates the submission of genomic and metagenomic data — reads, assemblies, bins and MAGs — to the European Nucleotide Archive (ENA). 

## Data sharing problem
Sequencing experiments generate valuable data that should be shared with the scientific community through public repositories, but data submission is a notorious bottleneck. Researchers must navigate complex database schemas, decipher lengthy documentation, manually organise metadata according to strict specifications, and execute multiple interdependent steps, all before a single read file reaches the archive. This often leaves data submission dreaded, delayed, or abandoned altogether, depriving the community of potentially valuable resources. SeqSubmit was started at the nf-core Hackathon 2025/2026 as a community-driven effort to remove that bottleneck.
![Data sharing]({{site.baseurl}}/assets/media/images/posts/seqsubmit/data.png){:width="800px"}

For biological sequence data, the [International Nucleotide Sequence Database Collaboration (INSDC)](https://www.insdc.org/) — comprising the EMBL-EBI European Nucleotide Archive (ENA), NCBI GenBank, and the DNA Data Bank of Japan (DDBJ) — provides a unified, internationally synchronised archiving system designed specifically for nucleotide sequences. Unlike general-purpose repositories such as Zenodo or Figshare, INSDC databases enforce standardised metadata schemas and structured relationships between biological data entities, and integrate deposited data into global sequence search systems, making it far more suitable for discovery and reuse. That structure comes at a cost, however: submission is considerably more complex than uploading a file, and each provider has different interfaces, tools and requirements.

## Automating data preparation for ENA submission 

The MGnify team, EMBL-EBI's resource for processing and storing metagenomic data, interacts with ENA constantly: retrieving raw metagenomic reads, and depositing the assemblies, bins and Metagenome-Assembled Genomes (MAGs) generated by our analysis pipelines. Over years of doing this at scale, we built up a set of Python packages to partially automate the process, and shared them with external collaborators. SeqSubmit consolidates that expertise into a single, fully automated Nextflow pipeline.

![Data submission]({{site.baseurl}}/assets/media/images/posts/seqsubmit/v1_submission.png){:width="800px"}
SeqSubmit takes final data products, computes any required statistics, compiles the metadata ENA requires, and performs a fully automated submission — organising everything around the Study that the original raw reads belong to, and linking derived assemblies and MAGs back to it through their SAMPLE records.

All submission is performed programmatically using ENA's [Webin-CLI](https://ena-docs.readthedocs.io/en/latest/submit/general-guide/webin-cli.html) tool, under the researcher's own Webin account, making it a scalable approach suitable for high-throughput workflows.

The pipeline currently supports four modes:

- **`reads`** — registers raw sequencing reads and their EXPERIMENT/RUN metadata (platform, instrument, library strategy, insert size, etc.), returning ERX/ERR accessions that downstream modes use as their source-RUN reference.
- **`metagenomic_assemblies`** — validates assembly FASTA files (contig IDs, minimum contig count, optional removal of human contigs), computes coverage with [CoverM](https://github.com/wwood/CoverM) where it isn't already known, and submits the assembly via *[assembly_uploader](https://github.com/EBI-Metagenomics/assembly_uploader)*.
- **`mags`** and **`bins`** — submit Metagenome-Assembled Genomes and bins, gathering additional mandatory metadata such as NCBI taxonomy, genome completeness and contamination, and environmental context (broad environment, local environment, environmental medium), before submitting via *[genome_uploader](https://github.com/EBI-Metagenomics/genome_uploader)*.

Each submitted assembly, bin or MAG is assigned its own ENA accession and reported back in the pipeline's output summary table, ready to be cited or cross-referenced.

## For the future 

Beyond its own test suite, SeqSubmit has already been used in production by a partner project to submit its data to ENA, resulting in over 26,000 bins and MAGs and thousands of assemblies deposited.

As the project grows, we hope to attract collaborators familiar with NCBI and DDBJ submission systems, so that SeqSubmit can expand beyond ENA to support the full INSDC collaboration.
