# MGnify blog

A Jekyll site served via GitHub Pages.
[View the live blog](https://ebi-metagenomics.github.io/blog/).

This site is used on the [MGnify website](https://www.ebi.ac.uk/metagenomics/) to display the latest blog posts.

## Development

The site can be built and served locally with Docker.

### Build

```bash
task build
```

The generated site will be written to `./build` on your machine.

### Serve locally

```bash
task serve
```

Open `http://127.0.0.1:4000/blog/` in your browser.
